# 🕊️ The Peace Game

> *Inspired by Monopoly — but stripped of every hotel, every bankruptcy, and every flipped table.*

A two-player terminal board game where the goal isn't to crush your opponent — it's to save the world. Race across a board of diplomatic missions and historic treaties, reduce the war risk from 100% to 0%, and become the ultimate peacemaker.

---

## How to Play

**Requirements:** Python 3.6+

**Run the game:**
```bash
python game.py
```

Two players take turns rolling a die and landing on peace-building spaces — from Cultural Festivals to UN General Assemblies. Each space reduces the global war risk. The first player to bring it to 0% wins.

Type `info` at any time during your turn to see current stats.

---

## Features

- 🗺️ 20-space board with a Monopoly-style layout
- ⚡ Space effects — alliances, breakthroughs, setbacks, extra turns
- 🌟 Random global events that affect both players
- 📈 XP and milestone system with permanent bonuses
- 🏆 Leaderboard that tracks the fastest peace records across sessions
